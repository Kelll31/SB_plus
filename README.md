# СБ+ — системы безопасности

Сайт для нефтебаз, химических производств и промышленных предприятий. React + TypeScript + Vite; панель управления на PHP и MySQL. Готовая сборка находится в корне, исходники — в `build_source/`. Навигация через `#/` работает на обычном файловом хостинге.

## Разработка и выпуск

```powershell
cd build_source
npm ci
npm run dev
```

`npm run check` проверяет TypeScript. `npm run release` проверяет и собирает сайт в `build_source/dist/`, затем копирует готовые файлы в корень. `npm run preview -- --host 127.0.0.1 --port 3000` показывает сборку. Vite не исполняет PHP: публичный сайт использует резервный `content.json`, для админки нужен PHP-сервер.

Главная начинается со сцены «От проекта — к защите объекта». Детализированная 3D-нефтебаза превращается из плоского чертежа в объёмную площадку. Перспективная камера пролетает над резервуарами, приближается к уровнемеру и газоанализатору, показывает передачу сигналов и входит в диспетчерскую. Сцена занимает весь экран; прозрачная шапка лежит поверх неё и возвращает светлый фон у следующих разделов. Вокруг основной площадки расположены подъездные дороги, второй резервуарный парк, трубные эстакады, склады, автоцистерна, фонари и лесополоса. Фотографические карты бетона, асфальта, грунта, стен и оцинкованной стали, HDR-освещение, сварные швы и следы осадков на окрашенной стали добавляют детализацию. Неподвижные детали площадки и окружения объединены по материалам для сокращения числа отрисовок. Трубы выполнены непрерывными трассами с касательными скруглениями; патрубки обоих рядов направлены в центральный коридор. Стойки ограждений опираются на фактическую поверхность конических крыш. Чертёж использует те же координаты резервуаров, что и модель; ориентация камеры и появление окружения плавно меняются у перехода к плану. Шесть этапов управляются прокруткой; кнопки этапов позволяют перейти прямо к нужному ракурсу, «К услугам» пропускает сцену.

Компонент — `src/components/IndustrialStory.tsx`, модель и стили — в `src/components/facility/`. Three.js загружается отдельным модулем. Все текстуры и HDR-панорама обслуживаются самим сайтом из `images/industrial/`; запросов к сторонним ресурсам у посетителя нет. Источники CC0 указаны в `build_source/public/images/industrial/CREDITS.md`. Повторное скачивание оригиналов: `python scripts/fetch-scene-assets.py`. Текстуры для браузера лежат в `images/industrial/r2/`. Их можно пересобрать командой `python scripts/compact-scene-assets.py` (Pillow и OpenCV). Во время прокрутки камера следует за сценарием. На этапах измерений и передачи сигналов продолжаются импульсы датчиков: до 60 кадров/с на компьютере и 30 на телефоне. Запросы кадров объединяются. Размер буфера ограничен и снижается при повторных пропусках кадров. На компьютере тени готовятся заранее, на телефоне выключены. Материалы загружаются до показа сцены, а план плавно появляется поверх индикатора. Рендер останавливается вне экрана, в скрытой вкладке и в статичном режиме. Геометрия и WebGL-контекст освобождаются при уходе со страницы. Макет иллюстрирует подход, а не реальное предприятие. Все показания явно отмечены как демонстрационные. Четыре уровнемера, три газоанализатора, четыре камеры, два пожарных датчика и СКУД соединены с общей стеной контроля (14 каналов). HTML-показания, уровень в модели и экраны щита используют одну функцию `demoTelemetry`.

Прокрутка остаётся нативной. «Без анимации», `prefers-reduced-motion`, недоступный WebGL и очень низкий экран включают статичное представление с текстами всех шести этапов; при недоступном WebGL используется SVG. Остальные анимации сайта находятся в `ScrollExperience.tsx`. Проверены телефон 375×667 и 375×812, планшет 768×1024 и компьютер 1440×950, переключение этапов, статичный режим и переход к услугам.

## Хостинг и админка

Нужны **PHP 8.2+**, PDO MySQL, fileinfo, сессии, HTTPS и права записи PHP в `api/storage/`. Конфигурация — `api/config.php` по образцу `build_source/public/api/config.example.php`. Таблицы `sb_admin` и `sb_content` создаются при первом запуске; пользователю БД нужны соответствующие права. Конфигурация хранится только на сервере.

На 15 ноября 2026 года на хостинге обнаружены PHP 5.3.3 и MySQL 5.1.73. HTTPS недоступен в современных браузерах. Публичный сайт на старом PHP читает список документов из `content.json`. Для входа в админку через сайт нужно обновить PHP и включить HTTPS в настройках хостинга.

### Редактор документов на Windows для текущего хостинга

Персональная сборка для Windows x64 находится в `artifacts/SBPlus-Documents-Ready-Menu.exe`. FTP уже настроен. Передавайте файл только владельцу сайта, поскольку в него встроены данные доступа. Их можно поменять через «Настройки FTP». На компьютере с редактором нужен только сам EXE.

При запуске из проекта откройте `Documents-Admin.cmd`. Этот способ использует установленный Python 3 с Tkinter и локальный `.env`. Для просмотра файлов из исходников нужны Pillow и pypdfium2. Редактор берёт `ftp_root` или `ftp_login`, `ftp_password` и при наличии `ftp_host`.

В окне выберите PDF или скан, введите название, выберите «Документы СБ+» или «Архив» и нажмите «Добавить на сайт». Чтобы изменить название, номер или файл, выберите документ и нажмите «Редактировать». Карточка сохраняет позицию на главной. Раздел меняется через «Переместить…», запись удаляется через «Удалить».

После выбора нового файла нажмите «Предпросмотр». Можно листать страницы PDF и увеличивать изображение. Файл отправляется на сайт после нажатия «Сохранить».

Щёлкните по строке правой кнопкой мыши, чтобы открыть файл, отредактировать запись, поменять раздел или показ на главной. Для карточек на главной в меню есть изменение порядка. Удаление требует подтверждения.

Все опубликованные документы доступны в реестре. Чтобы добавить карточку на главную, отметьте «Показывать на главной» при загрузке или у выбранного документа в списке. Главная и реестр проверяют обновления каждые 30 секунд в открытой вкладке и при возвращении к ней.

Во вкладке «На главной» перетащите документ мышью на нужное место. Порядок сохранится при отпускании кнопки мыши. Позиция карточки указана в столбце «На главной». Можно также использовать кнопки «На первое место», «Выше» и «Ниже».

Редактор обновляет `content.json` через FTP. Копии прежних списков из EXE находятся в `%LOCALAPPDATA%\SBPlus\DocumentsAdmin\document-backups`. При запуске из проекта используется `.deploy/document-backups/`.

На PHP 5.3 `content.json` на сервере является действующим реестром. Команда `hosting.py deploy` сохраняет этот файл при выпуске новой сборки.

### Вход через сайт после обновления хостинга

После подключения PHP 8.2+ и HTTPS откройте `https://poligonsb.ru/#/admin`. Ключ первого запуска и инструкция находятся в локальном `.deploy/ADMIN-SETUP.txt`. Владелец сам задаёт пароль не короче 12 символов. После создания администратора ключ не позволяет создать второй аккаунт.

Чтобы добавить лицензию или сертификат, введите название, прикрепите PDF, JPG, PNG или WebP до 8 МБ и нажмите «Добавить на сайт». Номер можно указать для поиска в реестре. Чтобы убрать документ, нажмите «Удалить» рядом с ним и подтвердите действие. Загруженный файл удаляется, если на него больше нет ссылок из контента. Для резервной копии нужны БД и папка `api/storage/`.

## Публикация

Доступы читаются из локального `.env` (ключи — в `.env.example`), не попадают в JavaScript и исключены из Git. Скрипт предназначен для `poligonsb.ru`, каталог `/www/poligonsb.ru`.

```powershell
python scripts/hosting.py prepare
python scripts/hosting.py backup --allow-plain-ftp
python scripts/hosting.py stage --allow-plain-ftp
python scripts/hosting.py deploy --allow-plain-ftp
```

Флаг обычного FTP используется с полученным разрешением владельца: хостинг не поддерживает FTPS. Владелец отдельно разрешил передать по FTP конфигурацию БД. Без флага скрипт требует FTPS.

Перед выкладкой сохраняется копия прежнего сайта в `.deploy/backups/`. Сначала загружаются ресурсы, `index.html` заменяется последним. После загрузки проверяются главная страница, ресурсы сборки и публичный API. Старые папки на хостинге автоматически не удаляются.

`python scripts/hosting.py package` создаёт локальный архив `artifacts/sb-plus-site.zip`. **Архив содержит приватную конфигурацию БД** и предназначен только для владельца и его хостинга. Не публикуйте `.env`, `.deploy/`, архив и инструкцию с ключом установки.

## Проверка API

`python scripts/test_api.py` проверяет вход, добавление и удаление документов, выдачу загруженного файла, CSRF и совместимость со старыми операциями API на временной SQLite-базе. Нужен локальный PHP в `.deploy/php/php.exe` с PDO SQLite и fileinfo. Подключение к MySQL проверяется отдельно командой `db-probe`.

## Контент

Промышленные фотографии, логотип и архивные сканы перенесены с прежнего сайта poligonsb.ru. Документы ООО «Полигон» явно помечены как архивные и не представлены как актуальные разрешения ООО «СБ+». Фотография камеры — Unsplash (`photo-1745867817232-9d92c805f6d2`). Все изображения размещены локально. Публикации появятся после добавления владельцем; вымышленных кейсов и клиентов нет. Контактная форма открывает почтовую программу посетителя.

Тесты сцены: из `build_source` выполнить `node --import tsx --test src/components/facility/facilityTour.test.ts`. Проверяются навигация, показания, траектория и непрерывность поворота камеры, направление патрубков и контакт стоек с крышей. Проверки зазоров охватывают газоанализаторы, трубы подачи и возврата, опоры эстакады и размещение поста относительно дороги, ограды и насосов.
